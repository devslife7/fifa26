## Plan Display

When creating a plan or task list, write it to a markdown file under `docs/plans/`
(e.g. `docs/plans/<short-kebab-name>.md`) and open it in a cmux markdown panel:

    cmux markdown open docs/plans/<name>.md

The panel renders markdown with rich formatting and auto-updates when the file
changes, so revise the file in place as the plan evolves. Keep plan files in git
(do not gitignore `docs/plans/`).
